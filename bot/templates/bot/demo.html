Autoveer WhatsApp Assistant

A menu-driven WhatsApp bot for a multi-brand dealer (Nissan, Bajaj, Ashok Leyland, Massey Ferguson) with 8 branches across Haryana. It answers 24×7, books test drives and services, and hands every enquiry to the right branch as a structured lead.

How it works

  1. Customer messages the dealership WhatsApp number
  2. WhatsApp Cloud API posts it to the Django /webhook/
  3. Engine state machine picks the reply: menus, forms, validation
  4. Lead saved in the database, managed in Django Admin
  5. Branch staff get an instant WhatsApp alert to call back
